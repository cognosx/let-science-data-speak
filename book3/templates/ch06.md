## Template: dataset README

| Section | Content |
| ------------------- | ------------------------------------------------------------ |
| Title and DOI | Dataset name, version, DOI |
| Summary | Three sentences: what, why, scope |
| Authors | Names, ORCID iDs, roles |
| Methods in brief | Sources, dates, search, screening, enrichment, extraction; pointer to full methods |
| Files | Each file with a one-line description |
| Codebook | Pointer to the codebook file |
| Quality | Key validation results |
| Limitations | Coverage, known biases, accuracy limits |
| Licence | Licence, and notes on source licences |
| How to cite | Citation text for the dataset (and the article) |
| Contact and updates | Who to contact; update plan |
