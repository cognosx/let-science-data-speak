## Template: two-page policy brief

| Section | Length | Content |
| ------------------------ | ------------------------ | ---------------------------------------------- |
| Title | One line | The question or the main message |
| Key messages | Three bullets | What the reader must remember |
| The issue | One paragraph | Why this matters now, for this reader |
| What the evidence shows | Three short paragraphs and one chart | One paragraph per key message |
| Options | A short table | Option, what evidence shows, trade-offs, uncertainty |
| Implications | One paragraph | What this means for the decision |
| About this brief | Three lines | Who wrote it, data sources and dates, conflicts of interest, link to full report and data |

## Template: portfolio review outline

| Section | Content |
| -------------------------- | ------------------------------------------------------------ |
| Summary | Two pages: questions, main findings, implications |
| Questions and scope | Agreed with the funder |
| Methods | Data sources, linkage, classification, indicators, benchmarks, match rates, verification |
| What was funded | By topic, stage, geography, recipient type, over time |
| What it produced | Outputs and outcomes linked to grants |
| How it compares | With the field, with need, with other funders |
| Beyond the numbers | Case studies: capacity, networks, policy influence |
| Limitations | Coverage, linkage gaps, attribution |
| Implications | For strategy and future portfolio |
